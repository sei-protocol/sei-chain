# sei-tendermint

Sei's fork of [Tendermint Core](https://github.com/tendermint/tendermint), the BFT consensus, mempool and P2P engine that `seid` runs on. It is built as part of `seid` from the repository root; see the root [README](../README.md) for build and run instructions, and [AGENTS.md](AGENTS.md) for the conventions that apply within this module.

For background on the consensus protocol, see "[The latest gossip on BFT consensus](https://arxiv.org/abs/1807.04938)".
